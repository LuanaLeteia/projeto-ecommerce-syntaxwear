# 🛒 E-commerce Silksong

E-commerce fictício de tênis desenvolvido como projeto de estudo de HTML e CSS. 

O site apresenta uma página inicial, categorias por estilo e gênero, seção de outlet, navegação responsiva e rodapé com newsletter e redes sociais.



## 🚀 Tecnologias utilizadas
- HTML  
- CSS  
- JavaScript



## 📱 Responsividade
- Celulares
- Tablets
- Desktop
